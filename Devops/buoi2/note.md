# cURL

- Viết tắt cho Client URL - một công cụ dòng lệnh được sử dụng để iểm tra kết nối từ URL, thực hiện truyền dữ liệu giữa các máy chủ và thiết bị thông qua nhiều giao thức khác nhau (như HTTP, HTTPS, FTP,...)

# Wget

- Là một công cụ trong linux. Bạn có thể sử dụng nó để lấy file từ các máy chủ khác nhau hỗ trợ các giao thức như FTP, SFTP, HTTP và HTTPS.

## So sánh với cURL và wget

### Wget

- Tập trung vào việc tải file từ web, crawl theo liên kết
- Hỗ trợ tải đệ quy (tự động theo các liên kết trong đường dẫn và tải thêm các file đó)
- Thường được dùng cho việc tải xuống các tệp lớn, mirror trang web

## cURL

- Mạnh về gửi request đa giao thức
- Hỗ trợ các giao thức như FTP, SFTP, HTTP và HTTPS.
- Phù hợp để test API, debug network hoặc gửi dữ liệu.

# Git

- Là một hệ thống quản lý phiên bản phân tán (Distributed Version Control System – DVCS). Sẽ lưu trữ tất cả các file trong toàn bộ dự án và ghi lại toàn bộ lịch sử thay đổi của file. Mỗi sự thay đổi được lưu lại sẽ được và thành một version

## Sự khác nhau giữa DVCS và VCS

- VCS là mỗi người sẽ kết nối tới server để lấy code hoặc commit

- DVCS: mỗi người khi clone repo sẽ có một bản sao đầy đủ của repository. khi server chính hỏng có thể lấy lại repo từ bất kỳ máy nào trong nhóm.
